## Ne amaçla kullanılabilir?

> Dolaptaki ürünlerin stok kontrolünü sizin yerinize yapar. Bunun yanında sürekli olarak ürün giriş çıkışını takip eder ve istediğiniz zaman hangi ürünlerin daha çok talep edildiği hakkında size bilgi ve Excel raporu sağlar.

## Gerekisinimler:
> Herhangi bir ek program veya yapıya ihtiyaç duymaz, tıkla çalıştır.

# Not: Program henüz deneme sürümündedir. İmzalanmadığı için Windows Güvenlik hatası verebilir!
